# Cosmos RF Power Website

## 📝 Project Description

This is the official website for Cosmos RF - a Canadian-based professional manufacturer specializing in high-performance radio frequency (RF) products. The website provides information about the company, products, solutions, and services for data center and energy storage systems.

## 🚀 Installation and Setup Guide

### System Requirements
- Node.js (version 18.0.0 or higher)
- npm or yarn

### Installation
1. Clone the project:
```bash
git clone [repository URL]
cd cosmos-web
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Build for production:
```bash
npm run build
# or
yarn build
```

5. Run the production build:
```bash
npm run start
# or
yarn start
```

## 🛠 Technologies Used

- **Framework**: Next.js 15
- **Programming Language**: TypeScript
- **Styling**: Tailwind CSS
- **Components**: Shadcn UI (based on Radix UI)
- **State Management**: React Query
- **Database**: PostgreSQL
- **Deployment**: Vercel/Netlify
